# Agent skills

This file documents the agent skills configuration for this repository. Skills like `to-tickets`, `triage`, and `to-spec` use these settings to coordinate with the rest of the repo.

## Agent skills

### Issue tracker

Issues are tracked as markdown files in `.scratch/` directories within this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

Issues use the default triage label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `CONTEXT.md` and `docs/adr/` live at the repo root. See `docs/agents/domain.md`.
